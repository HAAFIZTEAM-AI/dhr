# HAAFIZ verified institutional registry
# ---------------------------------------------------------------------------
#
# This file is the authority on who legitimately owns which domain. It is what
# separates "hbl.com.pk is HBL" from "hbl-secure-login.xyz is a criminal".
#
# Why it matters: every global blocklist (VirusTotal, Google Safe Browsing,
# PhishTank) is generic. None of them knows Pakistani institutions well, and
# none of them can tell a genuine HBL subsidiary from an impersonator. This
# registry is the single highest-leverage data asset in the project -- it is
# also the part nobody outside Pakistan can replicate. See docs/DETECTION.md.
#
# Format
#   bare-domain           grouped automatically by its second-level label
#   Brand Name | d1 d2    explicit brand with several official domains
#   # comment             ignored, anywhere on a line
#
# Rules for contributors
#   1. Only add domains you have verified from the institution's own site,
#      published annual report, or an official press release. Never add a
#      domain because it "looks official".
#   2. Add every TLD the institution actually owns. If Daraz owns daraz.pk but
#      NOT daraz.com.pk, leave the latter out -- then daraz.com.pk correctly
#      scores as "needs verification" instead of silently passing.
#   3. One brand per entry. Do not list Jazz the telco as an alias of JazzCash
#      the wallet; `validate_registry()` flags that collision.
#   4. Domains only, no paths. `sc.com/pk` is wrong; `sc.com` is right.
#
# Every addition here directly reduces false positives for real users.
